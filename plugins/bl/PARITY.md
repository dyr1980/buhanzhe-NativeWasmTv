# BBLL 1.5.2 对齐范围（BL JAR v2）

参照用户提供的 APK 资源与布局重建原生 View，接口按 `reference/source.json` 固定的 newBV 版本移植。以下区分已实现、已实测和仍存在的差异，不以图标存在代表全部功能完成。

| 范围 | 本版实现 | 验证边界 |
| --- | --- | --- |
| 播放器外观 | 底部渐变、标题/分 P、白色原图标、紫色焦点/进度条、右上角时钟、右侧设置、居中选集 | 在 7.1 实机截图检查；按屏幕尺寸等比缩放，全部是根 View 的子 View |
| 遥控器 | 方向/确认、MENU、播放/暂停、快进/快退、上下集、弹层逐级返回、播放中双击返回 | 7.1 实机自动化使用真实按键；补齐无焦点时恢复列表焦点 |
| 播放格式 | IJK 播放 MP4/FLV/HLS；API 16+ Exo core 合并 DASH AVC/AAC；API 14–15 用平台 MediaPlayer | 7.1 验证 DASH 独立音频/视频文件和 IJK，4.4 补测系统适配器；4.0 仍缺真机 |
| 播放设置 | 画质、AVC/HEVC、AAC 音轨、0.25–2 倍速、五种缩放、备用线路、进度/调试显示 | 画质/线路/倍速/缩放已做设备回归；HEVC 和所有高画质需账号、设备与服务端支持；系统播放器固定 1 倍速 |
| 分 P / 续播 | 选集、上下集、正序/倒序、随机、单集循环、播完停止、播完退出、本地续播 | 回归连续切换分 P；代理会话隔离，后台释放旧解码器后再创建下一解码器 |
| 点播弹幕 | WBI protobuf 分段、XML 回退、滚动/顶部/底部固定、颜色/描边、暂停/跳转同步、轨道避碰 | 7.1 真实站点已取得并绘制弹幕；三类弹幕用确定性视频测试并检查截图 |
| 弹幕设置 | 开关、字号、透明度、速度、占屏比、密度、weight 等级、关键词、顶部/底部开关 | 设置即时应用和保存；服务端 weight 用作筛选，不是本地 AI 评分 |
| 直播 | 直播列表、v2 AVC 画质与线路、失败自动换线及旧接口回退；5.0+ WebSocket 认证/心跳/zlib 弹幕、重连、前后台断连恢复；4.x 近期弹幕轮询 | 测试服务验证真实 WebSocket 认证包与压缩弹幕；真实接口结果记录于本地回归报告 |
| 字幕 | JSON 字幕、多语言选择、默认中文优先、字幕字号、切分 P 清空旧字幕 | 手动/默认字幕回归；请求带视频标识校验，字幕与弹幕避让控制栏 |

| 登录与账号 | 扫码、Cookie、本地/账号历史、收藏夹、稍后再看、关注列表、动态；点赞/投币/收藏/关注增删/三连接口 | 已接入，需要登录的操作有提示；用户已扫码登录，4.4 真实账号只读和确认取消流程已测；实际账号写入未执行 |
| 网络与封装 | 唯一 NativeHost 入口、全部网络复用宿主同一个 OkHttp；库裁剪、无 Activity/Fragment/WebView/Service 子类 | API 14 编译及 DEX 归属检查；不重复打包宿主 OkHttp/Okio/IJK，不携带新 `.so` |

仍有差异：

- 不支持高级定位/脚本/BAS 弹幕、会员渐变弹幕和直播礼物/醒目留言特效；直播使用 zlib 协议 2，不申请 Brotli 协议 3。
- Android 4.x 直播弹幕为每 3 秒读取近期消息，存在延迟且可能漏过高密度消息；这是对宿主旧 TLS 读写锁的兼容。7.1 使用 WebSocket。
- 不提供发送评论、发送弹幕、多账号切换或离线下载。没有把 newBV/BBLL 的全部应用模块搬入 JAR。
- 服务端观看心跳与进度上传尚未实现，目前按视频/分 P 保存本地播放位置。
- 搜索尚未移植 BBLL 的 T9、搜索历史和完整排序筛选；番剧时间表/追番页、动态细分筛选等页面仍需补齐。
- 部分外观/偏好（主题、缓存大小、默认启动页、简化按键模式）尚未逐项对齐。
- 未登录搜索可能触发站点验证，部分 UP 接口可能被风控；会员、地区和画质权限依服务端，不绕过验证。
- 本轮 4.4 真实画质切换出现准备超时，番剧媒体 CDN 拒绝访问（403）；未标记为全部修复。DASH 备用地址与会话内兼容回退不能保证站点所有媒体可用。
- 4.4 强制使用系统 MediaPlayer 时，切分 P 仍偶发准备超时；同设备 IJK 完整回归通过。此问题未标记为修复完成。

Android 4.0 是兼容目标，尚无本轮真机证明。UI 源码按 API 14 校验，DASH 引擎按 API 16 门槛加载；不能将 4.4/7.1 通过写成 4.0 真机已通过。
